# 灭战神决·盖亚 4766 · 武道循环裁定

用户原话（北京时间 2026-11-21）

> 武道是血-邪-天的顺序衍化，每次触发对应武道的挡伤效果后衍化至下一武道，由血道衍化一圈回来回满pp，逆转武道的情况下则是天-邪-血。血邪天挡伤条件分别是‘本场战斗自身在场前十回合’‘对方精灵本次在场超过两回合’‘非致命一击’的红伤

适用于魂印 1967 `86c26636`。覆盖此前旧测试把回到血道后的下一次衍化视作关闭的实现。原断言归档在 [gaia-before-next50-4766.test.cjs.txt](gaia-before-next50-4766.test.cjs.txt)，SHA-256 为 `230b77d32a7e9a4b5d746a1e745ad58985df6801c4f5ad16ac079e8f3156764b`。[修复前复现](gaia-before-cycle.log) 记录正转和逆转均在第一圈回到血道后关闭的实际失败。

正转循环血→邪→天→血，逆转循环血→天→邪→血。每次衍化进入末位血道恢复全部 PP。原技能逆转的时点和位置规则、整招沿用原武道并只衍化一次、逆转受红伤后按整招完整结算红伤反馈百分比伤害，以及外部机制封闭武道沿用已核历史规则。血道只在本场累计在场第 1–10 回合符合。邪道只在对手本次在场第 3 回合起符合。天道对非暴击红伤符合。固定、百分比与真实伤害各走原结算。
