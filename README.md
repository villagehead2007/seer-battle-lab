# 赛尔号对战实验台 · Windows 试玩版

2026 年 11 月 22 日人机与局域网更新版（AI Worker 67721786）。可在同一台电脑上操作双方，也可邀请同一局域网的朋友各自操作一队。ZIP 沿用上一版文件名。

## 第一次打开

1. 在 ZIP 上右键选“全部解压”，解压到自己可写的文件夹，保留里面的目录结构。
2. 打开解压后的文件夹，双击 **启动对战实验台.cmd**，保留出现的控制台窗口。
3. 浏览器会打开模式选择页。如果没有自动打开，复制控制台中的完整地址（以 /modes.html 结尾），粘贴到 Edge 地址栏。

## 选择模式和结算回合

- **进入单精灵实验台**。在 A、B 两边用本地精灵库搜索名称或编号，点击结果加载精灵，选好配招，点击“应用所选阵容并重新开局”。双方各选一项行动，再点击“结算回合”。
- **进入多精灵实验台**。为每只精灵配好技能和养成，点击“将当前配招和养成加入 A 队”或 B 队。每队可加入 1～6 只，选好首发后点“开始队伍对战”。双方各选技能、药剂或换宠，然后结算回合。
- **试玩本次更新**。搜索 SP 马尔修斯（20001）、米铃娜（4969）、幽冥帝尊·修罗（3592）或灾厄女神潘多拉（3396）。修罗与潘多拉可在配招区切换魂印，分别选择“焦魂冥墟”和“夜暝渊墟”。技能槽已满时先取消一项。
- **SP 马尔修斯的第五技能**。战斗中展开第五技能，从坚壁、极速、毁灭中选择可用形态。鼠标停在技能或形态按钮上可查看逐条效果。详情较长时，把鼠标移入提示框滚动。结算后可在状态栏查看预约切位，下回合开始时查看主位。

## 人机对战

在选择页点击 **进入人机对战**。你指挥 A 方，电脑指挥 B 方。为双方各组一队，在“电脑难度”选择练习、标准或困难，点击“开始队伍对战”，为 A 方选招并结算。普通技能可以调整第 1～4 槽的顺序，第五技能固定在第 5 槽。异常抗性按控制 13 项、弱化 19 项分组。

## 和同一局域网的朋友对战

1. 房主完整解压并启动，在模式选择页点击 **局域网开房**，再点 **房主进入 A 方**。保留启动窗口和模式选择页。
2. 点击 **复制邀请链接**，把完整链接发给同一 Wi-Fi 或有线局域网内的对手。对手用浏览器打开即可进入 B 方，仅房主需要运行试玩包。请将邀请链接只发给本局对手。
3. 页面优先推荐合适的 Wi-Fi 网卡。若双方实际通过另一张网卡相连，展开 **其他网卡地址**，复制对应邀请。仅在同一台机器试双人时，可用 **本机 B 方入口**。连接失败时先核对网络是否允许设备互访，以及房主电脑的专用网络防火墙是否允许包内 Node.js 接收连接。
4. 双方各自添加 1～6 只精灵，选好首发，点 **准备开战**。每回合选技能、药剂或合法换宠后，点击 **锁定本回合行动**；等两方都锁定，房主电脑会结算，并同步双方的战斗画面。
5. 从第 11 回合起可以投降。终局由房主选择 **快速重开** 或 **返回队伍选择**。结束联机时回模式选择页点 **关闭房间**；结束整个实验台时回启动窗口按 **Q**。

## 对战和回合详情

- **阵亡补位与选招**。队伍战出现补位提示时，点击待命精灵，再从它的技能中选一招。若改选另一只替补，要重新为它选招。双方都选好行动后，点击“确认补位并结算回合”。替补在本回合登场并行动，补位本身不额外消耗一次行动。A、B 两方操作相同。
- **查看技能详情**。单精灵和队伍战中，把鼠标移到普通或第五技能上可以查看技能名、威力、PP、命中、基础先制和逐条效果。长卡片可移入鼠标向下滚动，按 Esc 收起。
- **阅读回合详情**。在回合日志中查看受伤或回复的精灵、实际体力变化和伤害类型。满体力时的回复会显示 0 HP。圣甲·盖亚临终反击只计死亡当回合所受攻击红伤的完整结算值，反击本身造成真实伤害。

## 退出

回到启动时的控制台，按 **Q** 结束本次服务，再关闭网页。仅关闭网页时服务会继续运行。再次试玩时重新双击 CMD，并使用新窗口显示的地址。

## 运行环境

使用 Windows x64 电脑、可执行 CMD 的普通用户账户、现代浏览器和一个可用的本机端口。房主运行环境为 Windows x64，本版验证环境为 Windows 11 x64、Microsoft Edge。Mac 未验证。包内附 Node.js 24.21.0 x64 及许可证，解压后无需安装 Node.js、npm 或开发工具。模式选择页只监听本机，默认从 61780 开始寻找空闲端口。开房后会另启一个临时端口供局域网对手连接。在线资料查询需要网络，BWIKI 查询还使用系统 Windows PowerShell。

本版供试玩和调参，最终整库回归留到调参后。反馈问题时请附模式、双方精灵与配招、操作顺序以及对应回合的日志。
