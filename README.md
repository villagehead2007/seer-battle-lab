# 赛尔号对战实验台 · Windows 试玩版

下载后即可在浏览器里进行单精灵、多精灵、人机和局域网对战。包内含 Windows x64 版 Node.js 和 436 份本地精灵快照。单机试玩可以离线进行，无需安装 Node.js、npm 或游戏客户端。[下载试玩 ZIP](https://github.com/villagehead2007/seer-battle-lab/archive/refs/heads/trial.zip) · [主项目与开发进度](https://github.com/villagehead2007/seer-battle-lab)

## 第一次开战

1. 在 ZIP 上右键选 **全部解压**。打开解压后的文件夹，确认能看到 `启动对战实验台.cmd`、`runtime`、`data` 和 `dist`。
2. 双击 **启动对战实验台.cmd**，保留显示“按 Q”提示的控制台。浏览器会打开模式选择页。若没有自动打开，把控制台里以 `/modes.html` 结尾的完整地址复制到浏览器。默认从本机端口 61780 开始寻找可用端口。
3. 第一次可以选 **进入单精灵实验台**。在 A、B 两边搜索名称或编号，加载精灵，选好技能后点“应用所选阵容并重新开局”。双方各选一招，点 **结算回合**，在日志中查看谁先出手、造成多少伤害、触发了什么效果。

## 组队和人机

- **两人同屏**：选“进入多精灵实验台”。为一只精灵配好技能和养成，点“将当前配招和养成加入 A 队”或 B 队。两边各选 1～6 只，指定首发，点“开始队伍对战”。
- **自己打电脑**：选“进入人机对战”。你操作 A 方，也可以为电脑搭配 B 队。选择练习、标准或困难后开战，每回合只给 A 方选择行动。
- **换宠与补位**：正常回合可选择技能、药剂或换宠。队伍战提示阵亡补位时，先选待命精灵，再为它选招。改选替补后需要重新选招。

想试形态切换，可以搜索 **SP 马尔修斯（20001）**，在战斗中展开第五技能，查看坚壁、极速、毁灭各形态的可用条件。想比较不同魂印，可以搜索 **幽冥帝尊·修罗（3592）** 或 **灾厄女神潘多拉（3396）**，在配招区切换魂印后重新开局。鼠标移到技能上可查看逐条效果，长说明可滚动阅读。

## 比较倍率和养成

战斗中可查看双方各自的攻击克制倍率。队伍战也会显示待命精灵的对位倍率；换宠后以新对位为准。

养成区有三个刻印槽。955 个原始 ID 合并展示为 871 个等价候选；可按名称或编号搜索、按角数筛选、按单项属性或总和排序，再比较六维加成。可直接应用八组预设之一，也可手动调整单槽数值。称号、目镜和其他加成按当前队员分别设置；腐蚀套装会使目镜失效。

## 和朋友联机

1. 两台设备连接同一 Wi-Fi 或可互访的有线局域网。只有房主需要启动试玩包，对手使用浏览器即可。
2. 房主在模式页点 **局域网开房**，再点 **房主进入 A 方**。把 **复制邀请链接** 得到的完整地址发给对手，对手打开后进入 B 方。保留模式选择页，方便结束时关房。
3. 双方分别组队、选首发，点 **准备开战**。每回合各自选择行动，再点 **锁定本回合行动**。双方都锁定后，房主电脑结算并同步画面。
4. 对手无法连接时，在 **其他网卡地址** 中选择双方实际使用的网络，检查该网络是否允许设备互访，以及房主的专用网络防火墙是否允许包内 Node.js 接收连接。**本机 B 方入口** 只供房主在同一台电脑上测试。

## 结束试玩与反馈

结束联机时，由房主回到模式页点 **关闭房间**。结束整个试玩时，在最初显示入口地址和退出提示的控制台按 **Q** 或 **Ctrl+C**，然后关闭实验台标签页。仅关闭网页时，服务会继续运行。需要清理残留时，可双击 **清理残留实验台进程.cmd**。它会关闭这台电脑上识别到的全部实验台实例，包括其他实例的在用对局和房间。与朋友确认结束后再用。

遇到技能或魂印结算差异，请记下模式、双方精灵编号、配招、魂印版本和出问题的回合，附上该回合的操作与日志。反馈联机问题时请注明房主或对手视角。组队页会列出当前阵容仍待核验的多精灵词条。
