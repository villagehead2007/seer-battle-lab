# 赛尔号对战实验台

在浏览器里组队、配招，逐回合验证赛尔号的技能与魂印效果。你可以在同一台电脑上指挥双方、和电脑对战，也可以在同一局域网内与朋友各带一队。使用本地精灵库即可离线开战，无需登录游戏账号。

**想直接试玩？** Windows x64 用户可以下载内置 Node.js 的试玩包，完整解压后双击 `启动对战实验台.cmd`。[下载试玩分支 ZIP](https://github.com/villagehead2007/seer-battle-lab/archive/refs/heads/trial.zip) · [试玩版说明](https://github.com/villagehead2007/seer-battle-lab/tree/trial#readme)

## 从源码启动

1. 在 Windows 上准备 Node.js，推荐使用与试玩包一致的 24.x。项目使用 Node.js 内置模块，可以直接启动。
2. 在项目根目录双击 **启动对战实验台.cmd**。启动器会打开模式选择页，默认在本机 61648～61655 之间选择端口。若浏览器没有弹出，可在项目目录的终端执行 `node start.cjs --no-open`，复制输出中以 `/modes.html` 结尾的完整地址。
3. 用完后，双击 **清理残留实验台进程.cmd**。它会关闭本机识别到的全部实验台服务，包括其他实验台实例和已开的局域网房间。联机时请等双方结束再运行。浏览器里的实验台标签页可自行关闭。

## 选择玩法

| 模式 | 谁来操作 | 如何开始 |
| --- | --- | --- |
| 单精灵 | 一人操作 A、B 双方 | 各选一只精灵，配置技能，应用阵容并重新开局。双方选好行动后点“结算回合”。 |
| 多精灵同屏 | 一人或两人共用一台电脑 | 为两边各组 1～6 只精灵，指定首发后开始队伍对战。每回合可选技能、用药或换宠。 |
| 人机 | 玩家指挥 A 方，电脑指挥 B 方 | 先为双方组队，再选择练习、标准或困难。只需为 A 方提交行动。 |
| 局域网双人 | 房主指挥 A 方，对手指挥 B 方 | 房主点“局域网开房”，把邀请链接发给同一网络的对手。各自组队并准备，每回合双方锁定后由房主电脑结算。 |

联机时，房主用“房主进入 A 方”，对手用“复制邀请链接”得到的地址。对手只需浏览器。若电脑有多个网卡，可在“其他网卡地址”选择和对手处于同一网络的地址。“本机 B 方入口”用于在房主电脑上测试双方操作。

## 怎么验证一条效果

例如要看一次换宠会怎样影响魂印，先在多精灵模式给一方加入两只精灵，设好首发，再给另一方配好对手。把鼠标移到技能上查看威力、PP、基础先制和逐条效果。结算后对照战斗日志里的出手顺序、体力变化和状态，再换宠观察下一回合。

比较不同养成时，可以调整性格、学习力、套装、刻印和抗性，查看面板后再应用。复查单挑的随机结果时，保留同一随机种子、阵容和操作顺序；日志区的“导出”可以保存包含设置和逐回合操作的 JSON。

## 精灵库与实现进度

本次整理时，本地库有 **436 份按精灵编号保存的快照**，可按名称或编号搜索。每份快照记录种族值、属性、技能和魂印资料。需要在线查资料时，可使用 SeerAPI 或 BWIKI；日常使用已入库精灵可直接选择本地来源。[浏览精灵库](data/species/)

精灵已入库、单精灵机制通过验证、涉及队友或换宠的分支通过验证，是三个不同的进度。组队时可查看与当前阵容有关的词条；查某个效果的完成情况，请结合对应记录。[开发进度](PROGRESS.md) · [多精灵词条清单](MULTI-PET-TODO.md) · [阶段与验收标准](DEVELOPMENT-STAGES.md)

## 开发与反馈

- 浏览器页面及战斗引擎在 [dist](dist/)，本地 HTTP 服务入口为 [server.cjs](server.cjs)，自动化用例在 [tests](tests/)。在项目根目录运行 `npm test` 执行规则回归。
- 报告对战差异时，请附模式、双方精灵编号、技能或魂印版本、触发回合、操作顺序，以及实际和预期结果。单挑可附导出的 JSON；联机问题请注明发生在房主还是对手一侧。
