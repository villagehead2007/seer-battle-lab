## 养成与直接数值

- 双方独立设置等级 1–100、个体值 0–31、25 种性格（选项标明增益和减益）。个体值共用于六项能力。
- 六项学习力单项不超过 255，合计不超过 510；提供攻速、攻体和清空快捷分配。
- 六项额外加成用于录入体力上限药剂、刻印等面板收益的合计，范围 0–999；这是实验台的自定义加成范围，不是对官方各养成系统上限的声明。
- 实时预览最终面板；点击“应用并重新开局”才将设置用于新对局。
- “直接调整最终数值”中填写的项目覆盖计算值，未填写的项目继续自动计算。清除覆盖后恢复养成计算。
- 默认满级、31 个体、实干性格、0 学习力、0 额外加成。使用图鉴种族，不自动叠加刻印、套装或其他面板加成。

## 对战

A 方瀚宇星皇：万皇宗魄决、亘古圣辰决、圣世惩杀、瀚空之门、命宇轮回。
B 方王·雷伊：王·万霆朝宗、寰宇雷神断、雷裂残阳、传承王意、霹雳风暴。

分别选招后统一结算。先比较先制，再比较速度，同速随机。魂印、皇怒、吸强、回合压缩、免断、回血、吸血、封招、异常与反弹、PP 干扰均参与结算。魂印折叠面板可查看说明，状态标签显示余下回合或次数。所有技能均允许在任意实验等级使用。

随机种子控制同速先手、伤害浮动、暴击与概率技能效果。相同种子、养成参数和操作序列产生相同对局结果。种子不是难度或属性数值。

“导出”打开可复制的 JSON 记录，也可请求下载。记录包含初始养成配置、最终面板和逐回合操作。刷新或关闭网页不会保留当前对局，请先导出。

## 公式与版本边界

体力 = floor((2×种族+个体+学习力/4)×等级/100)+等级+10+额外加成。
其他五项 = floor(((2×种族+个体+学习力/4)×等级/100+5)×性格倍率)+额外加成。
学习力的小数保留至最后取整；额外加成不乘性格，手动覆盖优先于全部养成计算。

独立规则原型，尚未与当前《巅峰之战》逐项对齐。采用公开页游资料中的魂印（王雷伊为强化版），已接入套装与通用抗性，未接入刻印被动、联机和换宠。具体实验时序见 RULES.md 与页面折叠说明。

## v0.6 在线图鉴与通用规则

启动 `node server.cjs`，访问终端地址（本次为 http://127.0.0.1:61648/）。联网读取使用 PowerShell 7，优先本机捆绑 pwsh；可设置 WIKI_POWERSHELL 指向 pwsh.exe。不需要游戏账号或登录 Cookie。

按名称或编号搜索并加载双方，界面逐招显示适配状态。无第五技能最多携带四招，有第五技能携带一个第五与四个其他技能。满足适配检查后支持任意精灵及同种对战；未知魂印仍会阻止开局。所有精灵完整适配尚未完成。

通用效果：ID 1 吸血，4/5 自身/对手能力升降，6 反伤，43 最大体力回复；要求效果模板和完整技能描述都能解析。支持物理/特殊攻击、技能暴击概率 n/16。星皇622与王雷伊强化魂印527及原有十招保留专用适配。未实现词条不会被静默忽略。布布花真实资料目前14招中11招通过；齿突15、寄生种子13、光合作用的201暂不通过。

按需在线读取 Wiki 通用属性表（26个基础属性与复合映射），只提取Lua里的数据，不执行Lua。开局保存属性表、技能与精灵的内存快照；修改养成、重开和导出沿用快照。无全图鉴本地数据库。

连接策略遵循 MediaWiki API etiquette：串行请求、完成后间隔至少2.5秒、相同请求合并、30分钟内存缓存，最多160项。403暂停至少30分钟；429/567暂停至少15分钟；服务繁忙或maxlag暂停至少60秒。若Retry-After更长则遵守它，暂停期间取消排队的外网请求，缓存仍可读取。不伪装浏览器、收集Cookie、轮换IP或自动反复重试。`/api/wiki/status` 提供当前冷却与缓存状态。重启进程会清空内存缓存与冷却状态，不能借此绕过远端限制。

运行 `node --test tests/*.test.cjs` 验证所有规则。详见 RULES.md、VALIDATION.md。网络成功不代表长期稳定，未知魂印和复杂时序仍待适配。

## v0.7 效果ID组合与魂印事件

`dist/effect-registry.js` 是通用效果注册表：每个ID定义模板、参数范围、触发阶段与处理器。技能解析为 `{effectId,index,phase,params}` 指令列表，同ID重复出现保留不同参数、不同顺序。完整解析成功才允许开局，不执行Wiki提供的代码，也不忽略未知词条。

目前18个通用ID：1、2、3、4、5、6、8、43、57、101、191、760、821、842、913、946、983、984。王·万霆朝宗已迁为760+913+983+984组合；雷裂残阳的842增伤和101回血复用注册表，980封属仍保留专用时序。其余复杂招式保留原有验证过的处理器。

`dist/soul-registry.js` 为独立魂印ID空间，622与527按回合开始、用招后、回合结束分发；它们不是技能效果ID。魂印免伤/弱化免疫按魂印特性判断。尚未新增其他精灵魂印，未知魂印继续阻止开局。

这次实现组合架构并扩展通用词条，不代表所有精灵已完整适配。当前无法从模板明确恢复参数的技能、201多目标回复及特殊场景仍待核验。
